## The new staff page

New permanent Memory Wall route: `/memory-wall/`, visible through the **Google Sheets** link on the website's navigation. This is a simple, searchable staff directory with direct Google Sheets links, category grouping and each file's working tab. The labels are written for employees rather than technical readers; they avoid internal development terms and expose no worker ledger amounts.

## Which Google Sheets this Library actually reads

- `Project Resources — LIVE — V000002`: `project_resources`, `client_document_packets`, `resource_source_readback`. Used by the published project directory and client packet viewer.
- `Wage_List_11__PAYMENT__CLEAN_v1.1`: `Payment` plus `00_Manifest_History`. Used by the source-derived historical worker payment view. The page distinguishes this from the active worker-site Money & Goods originals.

Exactly **two distinct source workbooks** are fetched by the Field & Desk publication workflow. The user-facing page does not suggest that the other Sheets are fetched.

The page therefore has **35 distinct original Google Sheets links** total, backed by verified Drive IDs and existing working tabs. This page is for opening the owner's source Sheets; it is not a new place to enter duplicate data.
